# JCode 中文便携版

双击 **启动 JCode.cmd**。默认项目目录是同一文件夹下的 `Projects`。
也可以将项目文件夹拖到启动入口上，或在终端执行：

```powershell
& '.\启动 JCode.cmd' 'E:\我的项目'
```

首次使用按需输入 `/login` 登录模型服务商，再用 `/model` 选择模型。
输入 `/help` 查看中文帮助。原电脑上尚未保存的登录不会凭空迁移，
过期或无法跨机器使用的凭据需要重新登录。

配置、登录、会话、记忆及日志保存在 `data` 中。移动整个文件夹后，
通过启动入口运行即可重新定位内置工具；不要只复制 `jcode.exe`。
每次启动使用已有便携资料，首次打包后的电脑资料不会再次覆盖它。
资料内可能包含登录凭据，请按个人资料保管整个文件夹。

完成工作后用 `/quit` 退出。如仍有后台任务，双击 **停止便携版.cmd**
结束此便携副本的服务器，再从 Windows 安全弹出 U 盘。
停止入口会终止此副本的后台任务，请先保存工作并关闭其它便携窗口。

程序适用于 Windows x64，随附 Node、TypeScript 语言服务器、远程 MCP
适配器及运行库；不需要安装 JCode、Rust 或 Node。Git、Python、浏览器
等项目额外工具按目标电脑环境使用。模型与远程 MCP 服务仍需要网络。

`migration-report.json` 记录迁移情况。本机 Codex 专用的 `node_repl` MCP
不随包启用，其它配置保留。历史会话中的原项目路径仅作为历史记录，
项目文件需要另行放到 U 盘或目标电脑。

使用 `portable-manifest.json` 核对程序和运行时文件。`data`、`Projects`
会在使用过程中变化，不计入静态程序哈希清单。请使用本仓库打包脚本
更新便携版本，避免 `jcode update` 将定制版替换成上游版本。
